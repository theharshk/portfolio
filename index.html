01 / Backpressure & Bounded Queues

Real-time desktop streaming over local Wi-Fi causes TCP buffer bloat when client decoders lag. The server implements a bounded blocking queue of capacity 1 combined with an explicit client-side ACK handshake. If the mobile client has not acknowledged the previous frame, intermediate screen captures are dropped immediately, maintaining near-zero perceived latency.

02 / Native Win32 SendInput via JNA

Standard Java java.awt.Robot incurs JVM overhead and lacks native direct input injection for games and elevated windows. Using Java Native Access (JNA), the backend binds directly to user32.dll SendInput, injecting absolute cursor movements, mouse clicks, and Unicode KEYEVENTF_UNICODE keystrokes directly into the Windows OS message pump.

03 / Concurrency & Thread Separation

Screen frame capture, JPEG compression, and WebSocket outbound transmission are partitioned across isolated executor threads. Inbound mouse coordinate packets bypass image serialization queues entirely, ensuring sub-5ms touch responsiveness even under heavy graphic load.

04 / Security & Verification

Implemented local subnet IP binding, pre-shared token handshakes for WebSocket connection initialization, and unit test coverage with JUnit 5 & Mockito for packet serialization and client disconnect lifecycle handling.

01 / StateGraph Agent Architecture

Constructed a stateful cyclic graph using LangGraph that tracks conversational state, extracts clinical and discussion metadata into Pydantic models, and conditionally branches into verification or human confirmation nodes.

02 / 15s to <50ms Latency Slashing

Initial logging tool execution required repeated LLM re-prompting and unindexed metadata validation, peaking at ~15 seconds. By decoupling field extraction into schema-bound local validation, in-memory caching of clinic registries, and single-pass tool invocation, tool execution latency dropped to under 50 milliseconds.

03 / Context Pruning & Rate Limiting

Implemented dynamic conversation history trimming that maintains recent entity references and system instructions while truncating raw dialog history. This prevented token overflow and token-per-minute (TPM) throttling on Groq/Llama endpoints.

04 / Persistence & Containerization

Mapped extracted records to relational PostgreSQL tables with ACID transaction boundaries. The entire stack (FastAPI backend, PostgreSQL db, React/Redux SPA, Nginx) is orchestrated via Docker Compose for reproducible local and cloud deployment.
